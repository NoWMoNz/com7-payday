# เว็บเช็คของขวัญ

เว็บเช็คว่าใครส่งของขวัญแล้วหรือยัง ใช้ Next.js บน Vercel ข้อมูลอ่านและเขียนลง Google Sheet โดยตรง

- **หน้าหลัก** (แท็บแรก) การ์ดความคืบหน้ารวม และรายชื่อบริษัทพร้อมวงแหวนเปอร์เซ็นต์ (แดงต่ำกว่า 50% เหลืองถึง 80% เขียวหลังจากนั้น) กดบริษัทแล้วเจาะลงไปได้ **บริษัท → Chief → แผนก → รายชื่อ** บริษัทที่ไม่มี Chief จริง (คอลัมน์ Chief เป็นชื่อบริษัทเอง) จะข้ามขั้น Chief ไปที่แผนกเลย
- **ทุกคน** เปิดลิงก์ดูได้ว่าใครส่งแล้วหรือยัง ค้นหา (ชื่อ รหัส บริษัท Chief หน่วยงาน) และกรองตามสถานะ บริษัท Chief หรือแผนกได้ (ไม่เห็นรูป)
- **แอดมิน** เข้าสู่ระบบ → แตะชื่อ → ถ่ายรูปของขวัญ → กด "ยืนยันรับของขวัญ" ระบบจะ:
  - เก็บรูปไว้ใน Vercel Blob แบบ private (เปิดดูได้เฉพาะแอดมินที่เข้าสู่ระบบ)
  - ใน Sheet: เปลี่ยน `Status` เป็น `TRUE` และใส่เวลาใน `Timestamp`
  - ใส่ลิงก์รูปในคอลัมน์ `Photo` และชื่อแอดมินในคอลัมน์ `CheckedBy` (ระบบสร้างสองคอลัมน์นี้ต่อท้ายให้เอง)
- กดผิดคนแล้ว "ยกเลิกการรับ" ได้
- หน้าเว็บดึงข้อมูลใหม่ทุก 15 วินาที แอดมินหลายเครื่องจึงเห็นตรงกัน
- **หน้าภาพรวม** เปิดที่ `/dashboard` (หรือกด "ภาพรวม" ที่แท็บล่าง) ใครเปิดดูก็ได้ ไม่ต้องล็อกอิน แสดงจำนวนที่ส่งแล้ว, แยกตามบริษัทและ Chief (สลับเป็นหน่วยงานได้), กราฟจำนวนสะสมตามเวลา และรายการที่ส่งล่าสุด ดึงข้อมูลใหม่เองทุก 15 วินาที เหมาะกับเปิดทิ้งไว้บนจอใหญ่ มีปุ่มสลับ "กราฟ | ตาราง" และไม่แสดงรูปหรือชื่อแอดมิน

โค้ดอยู่ในโฟลเดอร์ [web/](web/)

## ลองบนเครื่องตัวเอง

ต้องบอกก่อนว่าจะอ่านรายชื่อจาก Sheet ไหน สร้างไฟล์ `web/.env.local` ใส่บรรทัดเดียว (ค่า ID คือส่วนระหว่าง `/d/` กับ `/edit` ในลิงก์ของ Sheet ซึ่งต้องแชร์แบบ "ทุกคนที่มีลิงก์ดูได้" ถึงจะใช้โหมดนี้ได้):

```
SHEET_ID=ใส่ID_ของ_Sheet
```

```bash
cd web
npm install
npm run dev
```

เปิด http://localhost:3000 แล้วเข้าสู่ระบบด้วย `admin` / `admin`

โหมดนี้ดึงรายชื่อจาก Sheet มาเก็บในหน่วยความจำ **ไม่เขียนลง Sheet จริง** และข้อมูลหายเมื่อปิดเซิร์ฟเวอร์

## ติดตั้งใช้งานจริง

### 1. สร้าง service account ใน Google Cloud (ประมาณ 5 นาที)

1. เข้า https://console.cloud.google.com แล้วสร้างโปรเจกต์ใหม่ (หรือใช้โปรเจกต์เดิม)
2. ค้นหา **Google Sheets API** แล้วกด **Enable**
3. ไปที่ **IAM & Admin → Service Accounts → Create service account** ตั้งชื่ออะไรก็ได้ เช่น `gift-check` แล้วกด Done (ไม่ต้องให้ role)
4. กดเข้า service account ที่สร้าง → แท็บ **Keys → Add key → Create new key → JSON** ระบบจะดาวน์โหลดไฟล์ JSON มาให้
5. เปิด Google Sheet → กด **แชร์** → ใส่อีเมล service account (ค่า `client_email` ในไฟล์ JSON) → ให้สิทธิ์ **ผู้แก้ไข (Editor)**

> ไฟล์ JSON นี้คือ key ลับ ห้ามส่งในแชทหรือ commit ขึ้น GitHub

### 2. Deploy ขึ้น Vercel

1. push โฟลเดอร์นี้ขึ้น GitHub (repo แบบ private ก็ได้)
2. ที่ https://vercel.com/new เลือก repo → ตั้ง **Root Directory** เป็น `web` → Deploy
3. ในโปรเจกต์ Vercel ไปที่ **Storage → Create → Blob** → เชื่อมกับโปรเจกต์นี้ (Vercel จะใส่ `BLOB_READ_WRITE_TOKEN` ให้เอง)
4. ไปที่ **Settings → Environment Variables** แล้วใส่ค่าตาม [web/.env.example](web/.env.example):

   | ชื่อ | ค่า |
   |---|---|
   | `SHEET_ID` | ID ของ Google Sheet (ส่วนระหว่าง `/d/` กับ `/edit` ในลิงก์) ต้องใส่เอง ไม่มีค่าเริ่มต้นในโค้ด |
   | `GOOGLE_SERVICE_ACCOUNT_EMAIL` | ค่า `client_email` จากไฟล์ JSON |
   | `GOOGLE_PRIVATE_KEY` | ค่า `private_key` จากไฟล์ JSON (คัดลอกทั้งก้อนรวม `-----BEGIN` ... `END-----`) |
   | `LOGIN_SHEET_NAME` | (ไม่บังคับ) ชื่อแท็บที่เก็บ Username/Password ค่าเริ่มต้น `รหัสผ่าน` |
   | `ADMIN_USERS` | (ไม่บังคับ) บัญชีสำรองที่ใช้ได้แม้อ่าน Sheet ไม่ได้ รูปแบบ `admin:รหัสผ่าน:ชื่อที่แสดง` คั่นหลายคนด้วย `,` |
   | `SESSION_SECRET` | ข้อความสุ่มยาวอย่างน้อย 32 ตัว |

5. กลับไปที่ **Deployments → ⋯ → Redeploy** เพื่อให้ค่าใหม่มีผล

ถ้าตั้งค่าไม่ครบ หน้าเว็บจะขึ้นข้อความบอกว่าขาดอะไร

## หมายเหตุ

- ระบบหาคอลัมน์จากชื่อหัวตาราง (`ชื่อพนักงาน`, `รหัสพนักงาน`, `บริษัท`, `หน่วยงาน`, `Chief`, `Status`, `Timestamp` ฯลฯ) ถ้าเปลี่ยนชื่อหัวตาราง ต้องแก้ใน [web/lib/people.ts](web/lib/people.ts) ด้วย
- ลิงก์ในคอลัมน์ `Photo` เปิดได้เฉพาะเบราว์เซอร์ที่เข้าสู่ระบบแอดมินในเว็บนี้อยู่
- ผู้ใช้และรหัสผ่านอ่านจากแท็บ `รหัสผ่าน` ใน Sheet เดียวกัน (คอลัมน์ `Username`, `Name`, `Password`, `Role`) เพิ่ม/แก้/ลบแถวใน Sheet ได้เลย มีผลภายใน ~30 วินาที ไม่ต้อง deploy ใหม่
- แอดมินอยู่ในระบบได้ 12 ชั่วโมง ถ้าลบแถวออกจากแท็บ `รหัสผ่าน` คนนั้นจะถูกตัดสิทธิ์ภายใน ~30 วินาที
- รหัสผ่านใน Sheet เป็นข้อความธรรมดา ควรแชร์ Sheet ให้เฉพาะคนที่ไว้ใจ
- รูปจะถูกย่อเหลือด้านยาวไม่เกิน 1600px ก่อนอัปโหลด เพื่อให้ส่งผ่านเน็ตมือถือได้เร็ว
